# Silicon Valley 앱 폴더 구조

`backend/apps/siliconvalley/` — Hexagonal + DDD 레이아웃 (Titanic 앱과 동일 패턴).  
`tests/`, `_docs/`는 이 문서에서 제외.

> **모듈 import:** `from siliconvalley.adapter...` (`PYTHONPATH=apps`)

---

## 1. 전체 트리

```text
siliconvalley/
├── __init__.py
│
├── adapter/                          # 외부 I/O (HTTP, ORM, PG)
│   ├── inbound/
│   │   ├── api/
│   │   │   ├── router_registry.py    # siliconvalley_router — main.py에 등록 (예정)
│   │   │   ├── schemas/              # Pydantic 요청·응답 스키마
│   │   │   └── v1/                   # FastAPI 라우터 (/siliconvalley/{character}/...)
│   │   ├── grpc/v1/                  # (예약)
│   │   └── websocket/v1/             # (예약)
│   └── outbound/
│       ├── mappers/                  # Entity ↔ ORM/DTO 변환
│       ├── orm/                      # SQLAlchemy 모델
│       └── pg/                       # PostgreSQL repository 구현
│
├── app/                              # 애플리케이션 계층
│   ├── constants/                    # intent_map 등 상수
│   ├── dtos/                         # 유스케이스 입·출력 DTO  ← 현재 5캐릭터 placeholder
│   ├── ports/
│   │   ├── input/                    # Use case 인터페이스 (ABC)
│   │   └── output/                   # Repository port (ABC)
│   └── use_cases/                    # Interactor (오케스트레이션)
│
├── dependencies/                     # FastAPI Depends DI wiring
│
└── domain/                           # 순수 도메인 (프레임워크·DB 무의존)
    ├── entities/                     # 캐릭터·도메인 엔티티
    └── value_objects/                # 피처 VO
```

---

## 2. 캐릭터 모듈 명명

Titanic의 `crew_*` / `passenger_*` 대신 **`{캐릭터}_{직무}`** stem을 사용한다.

| stem | 캐릭터 | 직무 (suffix) |
|------|--------|---------------|
| `hendricks_ceo` | Richard Hendricks | CEO |
| `gilfoyle_system` | Bertram Gilfoyle | System |
| `dinesh_dash` | Dinesh Chugtai | Dash (대시보드) |
| `dunn_coo` | (COO) | COO |
| `bighetti_hr` | (HR) | HR |

캐릭터 하나당 아래 파일 stem이 **동일**하게 반복된다.

| 레이어 | 경로 패턴 | 현재 |
|--------|-----------|------|
| Router | `adapter/inbound/api/v1/{stem}_router.py` | — |
| Schema | `adapter/inbound/api/schemas/{stem}_schema.py` | — |
| DTO | `app/dtos/{stem}_dto.py` | ✅ placeholder |
| Input port | `app/ports/input/{stem}_use_case.py` | — |
| Output port | `app/ports/output/{stem}_port.py` | — |
| Interactor | `app/use_cases/{stem}_interactor.py` | — |
| Provider | `dependencies/{stem}_provider.py` | — |
| PG repo | `adapter/outbound/pg/{stem}_repository.py` | — |
| ORM | `adapter/outbound/orm/{stem}_orm.py` | — |
| Mapper | `adapter/outbound/mappers/{stem}_mapper.py` | — |
| Entity | `domain/entities/{stem}_entity.py` | — |

## 5. 요청 흐름 (요약)

```text
HTTP  adapter/inbound/api/v1/*_router.py
  →   dependencies/*_provider.py
  →   app/use_cases/*_interactor.py
  →   app/ports/output/*_port.py
  →   adapter/outbound/pg/*_repository.py
```

Hendricks chat 예 (Titanic Smith chat 대응, 예정):

```text
POST /siliconvalley/hendricks/chat
  → hendricks_ceo_router
  → get_hendricks_ceo_use_case
  → HendricksCeoInteractor.chat()
       (Gilfoyle / Dinesh / Dunn / Bighetti 협업 — 추후 정의)
```
